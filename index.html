📖 사용 가이드
1
처음 한 번만 — 초기화
위 메뉴 초기화 버튼을 눌러주세요. 추천에 쓸 메뉴 목록이 채워져요.
2
추천받기
추천 탭에서 날씨·기분을 선택하고 버튼을 눌러요. 최근 3일 먹은 메뉴는 자동 제외돼요.
3
식사 기록하기
기록 탭에서 먹은 메뉴·식당·만족도를 입력해요. 기록이 쌓일수록 추천이 정확해져요.
4
데이터 저장 위치
기록은 이 기기 브라우저에만 저장돼요. 브라우저 데이터를 지우거나 다른 기기에서 열면 기록이 없어 보여요.
❓ 자주 묻는 질문
추천이 항상 비슷해요 ▾
메뉴 목록이 적으면 겹칠 수 있어요. HTML 파일의 sampleMenus에 주변 식당을 10개 이상 추가해보세요!
기록이 사라졌어요 ▾
기록은 브라우저 로컬 저장소에 저장돼요. 브라우저 데이터 삭제, 시크릿 모드, 다른 기기에서 열면 없어 보일 수 있어요.
같은 메뉴를 다른 식당에 등록할 수 있나요? ▾
네! sampleMenus에 menu 이름은 같고 restaurant만 다르게 두 줄 추가하면 돼요. 식당+메뉴 조합 단위로 추천해요.
